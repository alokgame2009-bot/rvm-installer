# RVM Panel - SkylerNodes

GitHub-ready one-command installer. The app source is packed into `rvm-app.tar.gz` so the GitHub web uploader does not need to upload nested folders.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/install-github.sh)
```

The installer asks for the GitHub repository URL, domain (default `rvm.skylernodes.fun`), and port. Cloudflare DNS is optional and is never enabled automatically.
